# DYP — Design Your Packaging

Custom branded beverage packaging platform. AI label design, 360° preview, sample ordering.

## Pages
- `/` — Homepage
- `/products.html` — Design Studio
- `/admin.html` — Order Dashboard (restrict access via Cloudflare Access)

## Deploy
Hosted on Cloudflare Pages. Auto-deploys on push to `main`.

## Local Development
Open `index.html` in any browser. No build step required.
